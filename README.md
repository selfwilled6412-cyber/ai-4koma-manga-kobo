# AI 4コマ漫画工房

B型事業所のイベント向けに、5つの質問へ答えるだけでChatGPT用の4コマ漫画生成プロンプトを作る静的WEBアプリです。

## 特徴
- HTML / CSS / JavaScriptのみ
- APIキー不要
- ログイン不要
- データベース不要
- 入力内容を保存しない
- GitHub Pagesで無料公開可能

## ローカル確認
`index.html` を直接開くか、簡易HTTPサーバーを利用してください。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。
